# О ресурсе

Репозиторий базы знаний [FPV FAQ](https://get-the-manual.github.io/fpv/)

Данные материалы исходят из личного опыта, наблюдений в FPV сообществе. Никакой рекламы, спонсорства, все по личной инициативе для продвижения хобби в массы. Приятного чтения!

Проект базируется на генераторе [Github Pages](https://pages.github.com/)

Содержимое страниц лежит в папке `docs`. Pull request'ы по улучшению ресурса приветствуются.


Сайт собирается и публикуется автоматически (GitHub Actions, `.github/workflows/build-site.yml`) при каждом push в `main`. Локальный запуск нужен только для предварительного просмотра.

Навигация (`nav:` в `mkdocs.yml`) ведется вручную: новую страницу нужно добавить туда самостоятельно.

## Установка

```
pip install mkdocs-material
pip install mkdocs-autorefs
pip install mkdocs-git-revision-date-localized-plugin
```

## Локальный запуск

```
mkdocs serve
```

## Медиафайлы

Медиа лежат в обычном Git, без Git LFS. Чтобы репозиторий оставался небольшим, действуют такие правила:

- **Анимации — только MP4, не GIF.** MP4 обычно в 5–20 раз меньше такого же GIF. На странице видео вставляется так, чтобы вести себя как GIF: запускается само, повторяется, без звука и без кнопок:

  ```html
  <video src="../Name.mp4" autoplay loop muted playsinline width="W" height="H"></video>
  ```

  `width` и `height` — реальный размер видео. Путь начинается с `../`, потому что MkDocs не переписывает пути внутри HTML.
- **Без пустых полос.** У MP4 нет прозрачности, поэтому прозрачные края GIF превращаются в белые полосы. Видео обрезается так, чтобы в кадре была только картинка.
- **Конвертация.** Скрипт `scripts/Convert-GifToMp4.ps1` (нужны PowerShell 7 и FFmpeg) конвертирует GIF, обрезает поля и меняет ссылку на странице:

  ```
  pwsh scripts/Convert-GifToMp4.ps1 docs/<папка>/Name.gif -UpdateLinks
  ```

  После конвертации исходный GIF удаляется. Подробный порядок действий — в `AGENTS.md`, раздел «Add an animation».
- **Длинные видео** (дольше минуты или со звуком) не добавляются в репозиторий. Вместо файла даётся ссылка на YouTube.
- **Изображения** сохраняются в разумном для веба размере. Скриншоты-фотографии лучше сохранять в JPG, а не в PNG.
- **Внешние картинки и анимации** лучше хранить в репозитории, чтобы страница не зависела от чужого сайта. Источник указывается на странице.

Ветка `gh-pages` пересоздаётся при каждом деплое одним коммитом (`mkdocs gh-deploy --no-history`), поэтому старые копии сайта в ней не накапливаются.
