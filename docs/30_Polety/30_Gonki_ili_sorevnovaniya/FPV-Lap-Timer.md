# Учет времени круга (FPV Lap Timer)

## Программы

### [FPV Lap Timer](https://www.fpvlaptimer.com/)

[Google Play](https://play.google.com/store/apps/details?id=com.babysquidstudios.fpvracetimerrn)  

Отлично определяет пролет, причем только в правильном указанном направлении. При пролете в противоположном направлении ложных срабатываний нет.  
Проговаривает время круга через текст to speech. выглядит немного криво, но вполне разборчиво.  
Есть возможность записать видео пролетов.  
Бесплатная версия, функционал вполне достаточный.

### [TinyFpvTimer for Android](https://play.google.com/store/apps/details?id=com.zinkner.TinyFpvTimer)

В бесплатной версии ограничный функционал.  
Не четко определяет пролет.  
Ложные срабатывания при пролете в противоположную сторону.
